## 🛠️ Sobre o Projeto

O **DNEA** não é apenas mais um boilerplate básico de ASP.NET Core. É um **Monólito Modular** de nível corporativo estruturado para eliminar semanas de configuração de infraestrutura repetitiva. Ele entrega uma fundação robusta baseada em **Clean Architecture**, permitindo que você escale o seu produto do MVP ao enterprise sem as dores de cabeça do acoplamento excessivo.

### 🔑 Key Technical Specs (Template Original):
* **Framework:** .NET 10 / ASP.NET Core
* **Arquitetura:** Monólito Modular com fronteiras de domínio rígidas e Clean Architecture
* **API Gateway & Routing:** Service Discovery integrado com Content Negotiation dinâmica (HTML / JSON)
* **Templating Engine:** Scriban para renderização dinâmica de alta performance
* **Resiliência e Observabilidade:** Health Checks avançados, tracing distribuído e telemetria nativa
* **Automação & Containerização:** Docker otimizado para multi-stage builds, Makefile inteligente e gestão centralizada de configurações

## 🧱 Infraestrutura Desacoplada & Módulos Prontos

O DNEA foi desenhado sob o princípio de **Plug & Play**. Cada componente de infraestrutura está isolado em seu próprio ponto/módulo, permitindo que você adicione, troque ou remova dependências sem afetar o núcleo do negócio:

* **🐳 Containerização Otimizada:** Dockerfile multi-stage enxuto e seguro, pronto para ambientes de alta performance e produção.
* **📬 Mensageria:** Abstração pronta para mensageria assíncrona (ex: RabbitMQ / MassTransit) com suporte ao padrão *Transactional Outbox*.
* **⚡ Cache:** Camada de cache distribuído integrada (Redis) com estratégias de invalidação e decorators para repositórios.
* **📊 Observabilidade Completa:** Stack pronta para produção com OpenTelemetry, Prometheus, Grafana e Loki para logs estruturados.
* **📦 Storage (Armazenamento):** Provedor de storage desacoplado (compatível com AWS S3, MinIO ou armazenamento local) para gestão de ficheiros e uploads.
* **⚙️ Configurações com Feature Flags:** Gestão centralizada de parâmetros via appsettings e variáveis de ambiente tipadas, com suporte a ativação dinâmica de recursos.
* **🏢 Multi-Tenant Nativo:** Arquitetura preparada desde o primeiro dia para isolamento de dados e tenants por schema ou identificador na base de dados.
* **🔄 CI/CD Automatizado:** Workflows do GitHub Actions prontos para testes automatizados, build, análise de código e deploy containerizado.
* **🤖 Makefile Inteligente:** Comandos unificados para subir o ambiente local via Docker Compose, rodar migrações, testes e gerar seeds com um único comando (`make up`, `make migrate`, etc.).
